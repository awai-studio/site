# **文化体験実施に関する確認書**

福成寺（住職：名流慈頼。以下「福成寺」という。）と髙廣信之（屋号：Awai Studio。以下「Awai Studio」という。）は、福成寺において実施する文化体験について、以下の内容を相互に確認し、これに沿って運営することに合意します。

## **第1条　体験内容**

1. 本体験は、福成寺を会場として実施します。
2. 体験内容は、坐禅と対話の案内およびお茶の時間を含むものとします。
3. Awai Studioのウェブサイトに掲載する体験内容については、本確認書の確認日時点の内容を基本とし、変更が必要となった場合は、事前に双方で確認します。
4. 体験の所要時間は、1回90分とします。

## **第2条　参加人数**

1. 参加人数は、1回につき最少3名、最大9名とします。
2. 参加者が3名に満たない場合は原則として催行しません。

## **第3条　販売価格**

自社サイトにおける販売価格は、参加者1名につき16,000円とします。

## **第4条　福成寺への支払額**

Awai Studioは、毎月末日を締日として、当月中に実施された体験分を、翌月5日までに福成寺の指定口座へ振り込むものとします。ただし、翌月5日が金融機関の休業日に当たる場合は、翌営業日までに振り込むものとします。振込手数料はAwai Studioが負担します。<br />
Awai Studioから福成寺への支払額は、1回の体験につき、参加人数に応じて次のとおりとします。なお、福成寺への支払額は、開催日の7日前に確定した参加人数を基準として算定します。

| 参加人数 | 福成寺への支払額 |
| -------- | ---------------: |
| 3名      |         20,000円 |
| 4名      |         25,000円 |
| 5名      |         30,000円 |
| 6名      |         35,000円 |
| 7名      |         40,000円 |
| 8名      |         45,000円 |
| 9名      |         50,000円 |

上記の支払額には、次の内容を含むものとします。<br /><br />

- 福成寺を会場として体験を実施すること
- 坐禅と対話を案内すること
- お茶の時間を設けること

この支払条件は初期運用における条件とし、実際の予約状況や運営上の負担などを確認しながら、必要に応じて双方の協議により見直すものとします。

## **第5条　予約方法**

1. 予約は、参加希望者から候補日を受け付けた後、福成寺に日程を確認する方式とします。
2. 予約候補日は、原則として火曜日、水曜日、木曜日、金曜日、土曜日とします。
3. 参加希望者には、前項の曜日の中から3つの候補日を選択してもらいます。
4. Awai Studioは、選択された候補日を慈頼住職に連絡し、対応可能な日を確認します。
5. 慈頼住職が選択した日を開催日として、参加希望者への案内および予約確定を行います。

## **第6条　開催時間**

桂離宮の見学予約との組み合わせやすさを考慮し、体験の開催可能な開始時間は、午前9時および午後3時とします。各時間帯の実施可否は、予約候補日の日程調整時に慈頼住職が決定します。

## **第7条　集合および交通手段**

1. 本体験は、福成寺での現地集合・現地解散を基本とします。
2. 参加者の交通手段は、原則として参加者自身で手配するものとします。
3. Awai Studioは、必要に応じて交通案内などの補助を行いますが、タクシーの送迎や交通機関の手配を体験料金に含めないものとします。

## **第8条　保険および事故への対応**

1. Awai Studioは、参加者のケガ、体験運営上の事故および福成寺施設の管理に起因する事故などに備え、必要な事業者賠償責任保険への加入または保険手配を行います。ただし、具体的な補償の対象および範囲は、加入する保険契約の内容によるものとします。
2. 事故などが発生した場合、福成寺とAwai Studioは、参加者の安全確保を最優先として相互に協力し、必要な対応を行います。
3. 保険の補償範囲を超える事項が発生した場合は、事故の原因、責任の所在および具体的な状況を確認したうえで、双方で対応を協議します。

## **第9条　ゲストによるキャンセル**

1. ゲストによるキャンセルは、Awai Studioのウェブサイトに掲載するキャンセルポリシーに従って取り扱います。
2. ゲストが体験日の7日以上前にキャンセルし、支払済みの代金について全額返金を受ける場合、その予約について福成寺側への報酬は発生しません。
3. ゲストが体験日の7日前を過ぎてキャンセルし、Awai Studioのキャンセルポリシーにより支払済みの代金が返金されない場合、Awai Studioは福成寺側へ第4条に定める支払額を支払います。
4. 支払い後24時間以内のキャンセルに関する例外その他、Awai Studioが公開するキャンセルポリシーに基づいてゲストが全額返金を受ける場合は、福成寺側への報酬は発生しません。<br /><br />

## **第10条　予約確定後の中止および日程変更**

1. Awai Studioの都合により、予約確定後の体験を中止する必要が生じた場合、決済手数料、返金手数料、保険手配費その他Awai Studioに実際に発生した費用をAwai Studioが負担します。<br /> 
また、福成寺に対しては、中止を決定した時点の予約人数を基準として、第4条に定める支払額を支払うものとします。
1. 福成寺側の都合により、予約確定後の体験を中止する必要が生じた場合、決済手数料、返金手数料、保険手配費その他Awai Studioに実際に発生した費用を福成寺が負担します。<br />  
また、予約確定後の体験を中止することによる補償として、福成寺はAwai Studioに対し、中止を決定した時点の予約人数を基準として、本体験の販売価格の30％に相当する金額を支払うものとします。
1. 前二項に定める決済手数料、返金手数料、保険手配費その他の費用は、実際に負担し、その金額を確認できる実費を対象とします。
1. 前各項にかかわらず、慈頼住職または髙廣信之の急病もしくは重篤な傷病、災害、警報の発令、公共交通機関の停止その他、双方の責任によらないやむを得ない事情によって体験を中止する場合は、前二項に定める支払額または補償金は発生せず、実際に発生した費用を福成寺とAwai Studioが折半して負担するものとします。
1. 中止または日程変更の必要が生じた場合は、判明した時点で速やかに相手方へ連絡するものとします。

## **第11条　ウェブサイトへの公開**

Awai Studioは、本確認書の内容およびウェブサイトに掲載する体験内容について、福成寺の確認を得たうえで、本体験をAwai Studioのウェブサイトに公開します。<br />
公開後に体験内容について重要な変更を行う必要が生じた場合は、事前に双方で確認するものとします。

本体験の掲載および広報は、次の予定で進めます。

- 2026年8月末：Awai Studio自社サイトで公開
- 2026年9月以降：SNSでの紹介を開始
